# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/).

## [1.0.0] - 2026-09-26

### Added
- Initial release of SearchIT
- Search input with "Explore" button and Enter-key support
- Quick-search suggestion chips (Artificial Intelligence, Black Hole, Renaissance, DNA, Mahatma Gandhi, Photosynthesis)
- Wikipedia Search API integration to resolve best-matching article title
- Wikipedia REST Summary API integration to fetch extract, thumbnail, and article URL
- Idle, loading, error, and result UI states
- Responsive, editorial-style visual design (Playfair Display / Inter / Lora typography, gold-and-parchment palette)
- "Full article ↗" link to the original Wikipedia page
